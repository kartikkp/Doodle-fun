# Doodle Fun

Improve the existing static drawing and tracing app into a robust, modern learning playground for kids ages 2–10 using iPhone and iPad. Preserve drawing, stamps, nine coloring templates, all uppercase/lowercase letters, digits, and export. Use adjustable age defaults, meaningful older-child challenges, accessible touch controls, accurate content, recoverable actions, and systematic QA.

Runtime remains dependency-free static HTML/CSS/JavaScript. No account, cloud child profile, ads, timer, leaderboard, or deployment migration is needed.

The user requires 20–30 meaningful visible activity choices after finding the four-card redesign too limited. The implementation provides 24 activities with 14 new games and explicit cards for each retained practice type. A delivered preview must remain playable when its local server stops; standalone HTML and offline-reload QA are required.
