# Doodle Fun

Improve the existing static drawing and tracing app into a robust, modern learning playground for kids ages 2–10 using iPhone and iPad. Preserve drawing, stamps, nine coloring templates, all uppercase/lowercase letters, digits, and export. Use adjustable age defaults, meaningful older-child challenges, accessible touch controls, accurate content, recoverable actions, and systematic QA.

Runtime remains dependency-free static HTML/CSS/JavaScript. No account, cloud child profile, ads, timer, leaderboard, or deployment migration is needed.

The user requires 20–30 meaningful visible activity choices after finding the four-card redesign too limited. The library expanded to 30 exercises, then the user asked to consolidate duplicate entry points and add actual sound games. The current design provides 21 activity families with 34 modes, retaining all 30 earlier exercises and adding four listening games. A delivered preview must remain playable when its local server stops; standalone HTML and offline-reload QA are required.

Provide starting difficulty for each year from 2 through 10, strategy coaching and per-mode challenge adjustment. Package the complete offline app as a simple iPhone/iPad app and validate it in iPhone simulators. Sound games must generate real offline audio, require completed playback before scoring, support replay and recover from interruptions. Actual child enjoyment remains a hypothesis until observed playtesting.
