# Phase 01 plan — Doodle Fun

## Objective
Make all original drawing, coloring and tracing activities robust and meaningfully age-adapted, with a clean iPhone/iPad touch interface.

## Context
User requested implementation and QA of every activity, preserving the existing GitHub app. Existing source was one index.html; it disabled all gestures, locked numbers until age8, had broken undo, size-changing canvases, and invalid whole-background trace scoring.

## Tasks
1. Rebuild the shared shell and drawing/coloring module: adjustable age/support settings, accessible native controls, safe storage, stable-resolution paper, bounded undo/redo, template retention, reliable export.
2. Rebuild learning modules: accurate normalized paths, prewriting/word variants, per-stroke validation, modeled quantity feedback, varied age-fit challenges and progress.
3. Verify every activity with pure unit tests, real Chromium/WebKit interactions, phone/tablet viewport matrix, independent code/pedagogy review; fix findings and deliver source plus QA results.

## Success criteria
All original templates and glyphs retained; no age hard locks; meaningful guidance by support level; confirmed destructive replacement with undo; full drawing survives navigation/rotation; taps and scribbling cannot earn tracing completion; real PNG export; tests pass, physical-device limitations stated.
