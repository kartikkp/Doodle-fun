# System volume and fuller Beat Studio feedback

## Objective
Remove the separate game mute/volume settings and make Beat Studio drum feedback substantially stronger at the same device media volume. Preserve gesture-only playback, silent rests, cancellation, retry and independent optional Read aloud.

## Context
The owner reports Beat Studio is still very quiet. Build 2 was distributed internally, but the currently installed version has not been reverified. The old engine applies `.5 * .55` default gain and persisted minimum `.5 * .15`, while drum-pad events last `.13` seconds. Native playback uses the media audio session without a software attenuation control. Preserve the owner's signing project and personal simulator.

## Tasks
1. Replace adjustable attenuation with fixed, bounded output; improve short drum energy. Remove game mute/volume UI and loading/persistence across listening and picture practice. Old settings must not silence or reduce the new engine. Update meaningful output, lifecycle, migration and trusted native checks.
2. Verify digital output at actual event durations, browser playback/recovery and iPhone trusted interactions; regenerate offline/native bundles, prepare build 3 and update TestFlight using the existing authorized groups. Record unavailable checks and Apple review blockers honestly.

## Success criteria
No game mute or volume slider, no legacy attenuation, stronger measured drum body with bounded output, recognizable effects/pitch, zero sound for Rest, no autoplay or post-cancellation audio, and successful relevant automated/native checks. Physical audibility is confirmed only by real listening feedback. Build 3 distribution status must be verified before claiming availability.
