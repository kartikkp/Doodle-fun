# Reliable preview and meaningful activity library

## Objective
Fix the user's observed activity launch failure and provide 24 directly accessible, meaningful activities with age-adjustable support.

## Context
The previously delivered localhost page remained open after its server stopped. Lazy imports failed on game entry. Existing green browser tests did not exercise this handoff. Four broad cards also hid the original breadth of practice choices.

## Tasks
1. Bundle all game code and styles into a standalone HTML app; add an offline reload cache and regression coverage for first entry with the network unavailable.
2. Add a 24-card categorized library with direct routes into specific tracing/counting tasks and 14 new games, scaling support across three age bands.
3. Verify every card, complete each new game, retry wrong answers, inspect phone/tablet layouts, and open the follow-up draft PR and update deliverables with exact evidence.

## Success criteria
- No activity needs a new network fetch on entry.
- All 24 cards launch successfully at all age bands and phone/tablet viewports.
- Games have distinct learning objectives and playable completion/retry loops.
- Standalone HTML works without a local server; installed offline cache can reload without one.
- Existing drawing, tracing, export, and persistence regression checks still pass.
