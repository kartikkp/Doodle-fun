# Natural coaching clips on request

## Objective
Bundle natural synthetic coaching clips offline and make all spoken coaching explicitly requested.

## Tasks
1. Generate reproducible Kokoro af_heart coaching clips with provenance, normalize and compress them, and embed them in the standalone/native build. No cloud runtime or child data transmission.
2. Implement cancellation-safe requested playback with dynamic device-voice fallback; test no unsolicited speech, navigation interruption, offline decoding and actual playback signals.

## Success criteria
Coach Hear uses a bundled clip for every mode/age. Speech never starts on entry, answer, success or hint alone. Instrument and Listen buttons remain intentionally audible. Report remaining physical-device validation honestly.
