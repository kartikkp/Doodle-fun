# Meaningful challenge and requested hints

## Objective
Retain all 21 activity families / 34 modes while improving the reasoning demand at each age 2–10. Hints and answer models appear only when requested. Age defaults are starting points, not assessments.

## Tasks
1. Review every mode as an educator; implement attribute/relation/causal tasks, richer language and quantities, precise tracing progression, and non-revealing retries. Preserve task-essential stimuli.
2. Verify deterministic generators over many rounds and complete every mode at every age in browser playthroughs, including wrong answers, requested hints and reset.

## Success criteria
All ages have solvable, unambiguous tasks with meaningful progression. No automatic solution model or spoken feedback. Younger co-play remains usable. Record agent review separately from actual child validation.
