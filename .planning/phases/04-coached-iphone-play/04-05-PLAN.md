# Full native iPhone QA

## Objective

Verify the packaged iPhone app across every activity and exact age, using current and compact iPhone simulators. Confirm real touch reachability and creative input separately from DOM-driven gameplay. Fix observed defects and preserve the owner's Xcode signing settings and existing simulator data.

## Context

The release was merged in PR #3. Prior browser coverage was broad, but native UI coverage was limited to launch, coaching, settings and sharing. The owner explicitly requested full iPhone QA after setting up Xcode signing.

## Tasks

1. Add an isolated native QA runner, 270 explicit age/activity integration cases, catalog touch sweeps and drawing/tracing recovery tests. Diagnose failures against actual simulator accessibility and pixels. Correct the observed scrolling/status-bar overlap in the native shell.
2. Run the complete corrected app on iPhone 17 Pro/iOS 26.5 and iPhone SE 3/iOS 18.6. Inspect retained screenshots and per-case reports, rerun incomplete/failed cases without weakening assertions, and publish a precise QA report and follow-up PR.

## Success criteria

- All 30 activities complete a meaningful play flow at each age from 2 through 10 in actual native WKWebView on both phones.
- All cards, coaching, hints and return navigation work through native UI in the planned age/orientation matrix.
- Trusted simulator gestures create and recover visible artwork, complete valid tracing, and reject incomplete tracing; all nine coloring pages are distinct and accept reversible fills.
- Native sharing, saved settings, local recovery and packaged integrity pass.
- The final report identifies the tested runtime, devices, evidence, corrected defects and limitations, and does not describe simulator or synthetic input as physical-device or child playtesting.
