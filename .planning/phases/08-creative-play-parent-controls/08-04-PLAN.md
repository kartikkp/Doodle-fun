# Parent help controls and integrated release QA

## Objective
Let parents allow hints, turn them off or require a PIN, while retaining essential instructions and making creativity easy to find.

## Tasks
1. Add optional local PIN protection with recovery, consistent hint/Coach gating and guarded settings/difficulty changes. Fix the triangle label illustration and pin drawing prominently across ages.
2. Integrate all features, synchronize offline/native artifacts, run relevant unit/browser/native QA, independently review and publish a reviewable pull request.

## Success criteria
Default remains help available. Approval is limited to the current round and is revoked on navigation/background. PIN is not stored in plaintext; recovery preserves artwork. Blocking hints covers alternate reveal paths while question audio/instructions stay usable. Tests retain meaningful scoring/layout assertions and original failures. Physical Pencil and child engagement remain direct acceptance checks. Owner signing project is unchanged; public App Store submission is not implied.
