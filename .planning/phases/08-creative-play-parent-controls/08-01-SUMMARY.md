# Drawing and tracing delivered

Drawing remains first in All activities and Create at every age. Ages five and up add marker and shape tools; ages eight and up add line, opacity and mirror drawing. Stroke compositing preserves opacity and Undo. Optional Pencil-only input rejects palm-first touch; pressure and coalesced pen samples remain supported.

Long tracing items open in a letter-focused phone view with whole-word context. Ink stays in canonical coordinates across letter switches, whole-word view and rotation. Enlarging the view changes screen-space motor tolerance without removing coverage/traversal requirements. Hint revocation stops the guide and retains the child's ink and counted dots.

Completed finite tracing sets offer an explicit fresh attempt, preserving old practice markers and best medals. An unfinished set cannot reset its mistake history. Chronological-age changes select the correct score bucket even when the practice step is unchanged.
