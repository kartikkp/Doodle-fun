# Creative learning review: ages 2–10

Reviewed September 27, 2026 against `studio-play.js`, `studio-play.css`, `draw.js`, their tests, and the existing [educator review](educator-activity-review.md) and [age-adaptive design](age-adaptive-design.md). This is a code and interaction review using an educational design lens. It is not credentialed educator validation, observed child playtesting, or evidence of learning outcomes. Age supplies an adjustable starting point.

The initial review found that Balance disclosed its mystery value, Mirror gave ages 8–10 the same task, and Pour reduced planning demand when it introduced fractions. Those findings prompted the corrections described below. The table records the resulting implementation, not an unimplemented curriculum proposal. All three touch games retain visible task evidence, reversible actions, explicit Check, quiet feedback and optional hints. Drawing, mirror free creation and Beat maker are ungraded.

## Findings and disposition

- **Corrected — older balance answer giveaway and repetition.** `buildStudioRound()` now supplies an indirect equality, then distinct age-9/10 piece constraints. `balanceComplete(pans, round)` checks equality, exact piece count and required number of values. A level pan with 5+5+2 fails the age-10 opening rule; 5+5+1+1 passes. The clue is necessary mathematical evidence; it no longer states the unknown's value. Solving tests cover 200 rounds at every age.
- **Corrected — identical older mirror task.** Age 8 uses horizontal/vertical axes, age 9 one diagonal, age 10 both diagonals. `mirrorSource()` maps actual coordinate reflections. Source tiles stay visible; increased memory load is not the progression. Diagonal color symbols are themselves reflection-symmetric, avoiding contradictory decorative orientation. Purple dashed axes and solid/dotted tile borders distinguish the model from editable tiles.
- **Corrected — compact-phone geometry and audio interruption.** Six 48px tiles plus gaps require 303px. Studio margins now accommodate that at 320px without shrinking targets. Native background notification now stops Beat maker, including pending audio startup, even when WebKit remains visible. Visual review also separated the tilted pan from its observation text.
- **Corrected — pour variation and challenge sequencing.** `POUR_BANKS` provides three to six solved problems per age. Each bank is at least as large as its medal set, so consecutive problems do not repeat within a set. Ages 6/7/8/9/10 have minimum solution lengths of 4/6/6/8/10 pours; fractional labels preserve the conserved integer-unit arithmetic. These lengths validate planning demand, not an optimal-move score: ordinary exploratory pours do not count as mistakes, and Undo remains available. Jug heights use one common unit scale within the problem.
- **Follow-up — young-child instruction access.** The studio controller presents written instructions without a dedicated per-round Hear control. Ages 2–4 should be described as supported exploration until observed independent use demonstrates otherwise. Add requested instruction audio independent of the parent's hint policy; never auto-play a solution.
- **Follow-up — creative continuity and composition prompts.** Beat maker's four-step pages protect touch size, but the playhead can move beyond the visible page. A page indicator or optional playback-follow view would help. Optional age-specific prompts could suggest repeats, contrasting sections and purposeful rests without grading art/music. Mirror's Create freely/Return to challenge currently replaces the current picture; preserve separate drafts for those two states in a follow-up.

Drawing's added tools perform real operations, with stroke opacity, shape previews and mirrored strokes preserved correctly in Undo. Pencil-only mode rejects touch before it can claim the paper; pressure/coalesced pen input has synthetic coverage. Physical iPad/Pencil pressure feel, palm behavior and tilt expectations remain device acceptance work. No native PencilKit migration or tilt-sensitive brush is claimed.
