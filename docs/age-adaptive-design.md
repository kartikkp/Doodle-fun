# Age-adaptive activity design

Design contract, September 26, 2026. Scope: all 21 catalog families and 34 playable modes, ages 2–10. This describes the intended presentation and implementation work; it is not a claim that children have tested the redesign or that every activity is a complete grade-level lesson. Age is a starting point, with independent support adjustments.

## What the audit found

The catalog currently gives 21 families five category-colored cards with emoji. Most playboards use the same white rectangle, oversized heading and permanent help panel. Age-10 arithmetic is meaningfully harder than preschool counting, but it still looks like preschool counting. Coach, age summary, mode tabs, engine header and another age/round label repeat before the child reaches the action. The inspected 375 × 812 Beat Studio capture puts Hint below the initial viewport; the 820 × 1180 Melody Echo capture spends a full side column on repeated introductory help. This makes simple games look complicated while advanced games still feel young.

Sources: `catalog.js`; the six engine renderers and their styles; `app.js` / `app-shell.html`; existing `work/system-volume-qa-2026-09-26/visual` and older-discovery captures. Existing tracing paths, coloring templates, geometry and counting frames are useful structured graphics. Most familiar objects and story steps are platform emoji, so visual meaning and weight vary by device. Keep the useful geometry and replace the semantic object artwork with bundled SVG.

## One language, three visual stages, nine starting points

Use selected **appearance age** for visual maturity and effective **challenge age** for questions, amounts and support. An older child choosing easier work keeps a mature interface. Neither reading ability nor school grade is inferred from age alone. Preschool, kindergarten and grades 1–5 are approximate design references, not labels shown as assessment results.

| Age | Default visual behavior | Learning presentation |
|---|---|---|
| 2 | One focal object/action, two large choices where applicable, 64–72px primary targets | Show what can be touched; concrete quantities; grown-up co-play; optional spoken instruction |
| 3 | Two or three objects in a recognizable scene; 64px targets | One short action at a time; picture-supported before/after and count language |
| 4 | Three choices, clear grouping, 60px targets | Match a property, continue a short unit, small concrete amounts |
| 5 | Three or four choices, 56–64px targets, simple captions | Link picture and symbol; visible task model, optional worked example |
| 6 | Four choices, ordered work area, 56px targets | Combine/reverse, part–whole, letter sounds and grouped counting |
| 7 | Four or five relevant items, 52–56px targets | Show relations and strategies without printing the answer; explain through a picture choice |
| 8 | Clean studio surface, structured diagrams, 52px targets | Bridge objects to symbols; transform/plan rather than only add more pieces |
| 9 | Compact, age-respectful diagrams; 48–56px targets | Place value, missing operands, properties, relation matching and route constraints |
| 10 | Same readable targets, richer task constraints and neutral illustrations | Multi-step reasoning; compare strategies; no speed requirement or tighter motor tolerance as a substitute for thinking |

All controls remain at least 48 × 48 CSS pixels, including close, reorder, canvas tools, selectors and arrow pads. Additional objects never mean smaller controls. Use a restrained paper palette, deep ink, one family accent, soft scene backgrounds and consistent rounded outlines. Preschool art uses recognizable objects with gentle expressions; older art uses the same semantic objects with cleaner diagrams, less decoration and no babyish vocabulary. Typography, symbols and geometry remain readable, not miniature. Color is never the only state cue; selection also has outline/check/text.

## Shared shell and responsive contract

Keep one concise activity title and the current mode, an obvious Back control, and a compact Coach entry. Remove category slogans, duplicate age labels and permanently expanded coaching prose from the play area. Keep all modes visible through the same labeled navigation; on narrow screens it scrolls without shrinking buttons. A changed support level remains discoverable in Coach. Hint is an explicit, consistent 48px control close to the task. Teach an action with one sentence and a picture; place longer explanations in Coach.

On phones, use the full available width with 12–16px outer gutters, a vertically flowing task, then its actions. A 375px portrait screen should expose the first meaningful action without passing a full help card. At 320px, reflow choices and permit vertical scrolling. Never clip the page to force everything above the fold. Landscape uses task and controls side by side when each retains its minimum size; otherwise it scrolls. iPad uses a centered board and a narrow optional tool rail, not a permanent wall of helper text. Honor all safe-area insets. Drawing remains a square working surface sized from the available viewport, with its existing state-preserving resize logic.

Hints must not reveal answers automatically after a wrong attempt. Keep intrinsic stimuli visible: tracing guide, pattern sequence, maze walls, task quantities and selected letters. Put worked solutions, highlighted next answers and target sound labels behind an intentional Hint. A hint may first suggest a strategy and then show a worked model. Accessible names describe the real item; never remove useful names to make a weak question artificially harder. Audio begins only from the existing deliberate playback actions. Device buttons control volume. Spoken help uses explicit Hear actions; the legacy Read aloud toggles are removed. Playback errors and interruption recovery stay visible.

## Family and mode presentation map

Each row covers a distinct family; every mode ID is listed. The age columns specify the playboard, not just a card color. Changes to task semantics belong to the educator's age-by-age contract and must have corresponding generators, validation and tests; a cosmetic scene cannot claim an unimplemented task.

| Family / modes | Ages 2–4 | Ages 5–7 | Ages 8–10 |
|---|---|---|---|
| **Doodle studio** `draw`, `coloring` | Easel, chunky pencils, a large uncluttered sheet; concrete mark/circle/shape ideas. Coloring uses recognizable outlines with large regions. | Artist workbench; optional pattern, habitat and before/after prompts; full drawing tools within reach. | Illustration studio; optional composition, light, limited palette, annotated invention and comic prompts. Finished work stays central; changing appearance must not clear pixels or Undo. |
| **Trail studio** `prewriting`, `uppercase`, `lowercase`, `word-tracing`, `number-tracing` | Trail map with clear start/finish dots and broad real paths. First lines default; letters/numerals remain optional foundations. | Handwriting notebook, baseline and sequential strokes; short words connect to a meaningful picture. Capital and lowercase examples remain distinct. | Clean drafting sheet. Words gain authentic vocabulary/spacing challenges through content changes; line/case/numeral practice is honestly called foundations. Do not make older handwriting harder only by thinning tolerance. |
| **Letter buddies** `letter-match` | Two friendly letter tiles, equal visual weight, matching by case with support. | Case pairs in a reading desk; related sound/word context can support teaching without marking the partner. | Typography desk with mature letterforms and optional word context. Case recognition remains foundations unless the task changes; no decorative distractor overload. |
| **Build a word** `word-build` | Familiar illustrated object above a few letter tiles; task/model distinction explicit. | Word workshop, phoneme/group slots where the task supports them, broader recognizable picture bank. | Illustration plus a real clue, long-word chunks and plausible distractors. Keep the spelling model behind Hint; use age-appropriate vocabulary rather than only longer tiles. |
| **Count & make** `counting`, `ten-frame` | Orchard quantities with individually touchable fruit; five-frame tray. | Count in groups, ten/twenty frames on a structured work mat; zero is shown as an empty set. | Number lab with clean counters and grouping. Current ≤20 practice is foundations; advanced decomposition requires a real task upgrade, not hundreds of dots. |
| **Number stories** `addition`, `subtraction`, `number-bonds` | Picnic join/remove/part scenes; visible whole and parts, one action. | Bar/part–whole diagrams grow from real groups; unknown slot visibly belongs to the equation. | Place-value desk: two/three-digit operands, regrouping and varied unknown positions. Optional tens/hundreds strategy diagrams, compact text by default. Preserve the existing answer-independent distractors and complete-equation feedback. |
| **Groups & sharing** `sharing`, `equal-groups` | Picnic mats and food pieces; one piece per friend, rows clearly separated. | Equal rows and group brackets make the relation visible; remainder tray only when meaningful. | Packing/array board, group counts and equation. Existing older multiplication is substantial; fair-sharing's small repeated-cookie task remains a warm-up until reasoning changes. Never draw hundreds of edible items for a large product. |
| **More, less, same** `compare` | Two baskets at a common baseline, quantity is the variable, no decorative answer cue. | Equivalent sets, common-scale diagrams and relation symbols with spoken labels. | Compare numeral/place-value cards, then find the difference. Optional blank bar strategy; do not pre-size bars according to the answer before the child reasons. |
| **Put it in order** `size-order`, `number-order` | Garden objects with a shared baseline; left-to-right receiving slots. Number stepping stones use visible start/direction. | Measurable sizes, forward/back sequences and clear empty slots; tap-to-place and Undo. | Measurement/sequence strip. Older numerical increments/decrements use six readable slots. Size discrimination needs changed measurement reasoning; smaller visual size gaps alone do not create an age-10 lesson. |
| **Shape & color detective** `shape-match`, `color-match` | Shape inset board and artist swatches with isolated variables; target always clear. | Geometry outlines with properties, rotated shapes when the task supports them; color families use named swatches. | Geometry design lab and color-study board. Property/transform/color-relation questions require actual new contracts. Exact-copy matching stays available as a labeled warm-up. |
| **Pattern parade** `patterns` | A parade rail of illustrated tokens; repeated unit visible but not highlighted as the solution. | Tile strip with alternate units; use spatial brackets only as an optional hint. | Number-rule notebook with a missing internal/final value. Keep every relevant value readable and show an optional difference row, not an automatically revealed rule. |
| **Sort it out** `sorting` | Recognizable tray contents and pictorial baskets; select item then destination, no drag requirement. | Sorting station with clearly labeled properties/categories and stable targets. | Museum/transport classification bench; category relations and rule changes need new content. Scene detail must not obscure which attribute matters or encode the destination through matching backgrounds. |
| **Spot the difference** `odd-one-out` | Three simple illustrated tiles with one differing property. | Observation cards with a single meaningful contrast; explain through a property choice when supported. | Specimen/geometry grid with a specified rule and plausible candidates. Avoid multiple defensible outliers, unequal decoration or tiny differences that only test eyesight. |
| **Memory garden** `memory` | Two/three pairs of recognizable illustrated leaves/animals; stable positions and generous targets. | Four pairs in a tidy garden grid; optional deliberate pair reveal and reversible retry. | Number garden: multiplication/result at age 9; equivalent fractions at age 10. Calm mature card backs, stacked fractions, optional fraction-bar hints. No color pairing or artwork that gives away equivalent values. |
| **Pathfinder** `maze`, `directions` | Clear path tiles with one traveler and goal; big arrows; moves are reversible. | Field map with walls and a command strip, one current position and coherent direction language. | Route-planning map with existing ordered checkpoints; command/rule extensions only when implemented. Keep walls, checkpoint order and Undo visible; no shrinking cells below 48px. |
| **Story steps** `picture-sequence` | Two/three fully illustrated causal panels showing the same setting over time. | Four event panels in a storyboard; consistent people/objects make ordering meaningful. | Illustrated process/story panels with plausible dependencies and richer content. The existing two scripts cannot be made age-10 appropriate just by adding decorative frames. Do not print ordinal numbers or reveal the full order outside Hint. |
| **Shape builder** `make-a-shape` | Pegboard with large corner targets and a faint intrinsic target outline. | Geometry workshop with side/corner progress and clear joining paths. | Drafting board, decoy points and property constraints when implemented. Do not depict a full solution by connecting the answer points before Hint. Preserve clockwise/counterclockwise valid completion. |
| **Sound detective** `sound-match` | Recognizable drum/bell/shaker/wood-block illustrations; Listen and choice exploration have distinct labels. | Small instrument studio; first/last sound task written once, deliberate replay. | Sound investigation desk with event-position strip, clean instrument drawings and independent preview controls. Neutral playback pulse must not identify the answer. Sound names/model remain an intentional hint where required. |
| **Higher or lower** `pitch-path` | Two clear contour choices on the same scale, no score pressure. | Up/down/same note paths; visible axes removed unless useful. | Five contour diagrams on an equal-scale grid. Subtler intervals are shown as listening work, with identical visual choice treatment; a target contour appears only after Hint. |
| **Melody echo** `melody-echo`, `rhythm` | Large xylophone-style tone pads and body-action illustrations. Clap, tap and stomp sound; Rest is visibly quiet. | Stable ordered pad positions, numbered sequence slots, optional picture model. Rhythm action cards clearly depict a hand clap, fingertip tap, shoe stomp and open-hand rest. | Compact instrument deck with all pads reachable; sequence length/memory grows without making pads smaller. Picture practice stays untimed order memory, distinct from Beat Studio's relative gaps. |
| **Beat studio** `beat-studio` | A recognizable full-bodied drum and two/three count dots; copy the count at any speed. | Drum workbench and response markers; short/long gaps introduced without a countdown. | Percussion studio; own-response timeline and relative-spacing comparison after Check. Target gap model belongs behind Hint. Ready/listening/your-turn states must make the pad's availability obvious rather than presenting an unexplained pale disabled circle. |

## Asset and implementation contract

Bundle structured SVG from `activity-art.js`, with a 240 × 160 family scene and reusable semantic object drawings. Each family has a recognizably different composition: easel, trail map, reading desk, word tiles, orchard/frame, part–whole board, packing trays, comparison baskets, measurement rail, geometric palette, pattern strip, sorting bench, magnifier, memory garden, route map, storyboard, pegboard, instrument set, contour graph, tone deck and drum. Changing the background hue is insufficient.

`activityArt(familyId, {age, variant})` provides catalog/heading art. `objectArt(id, {age})` provides familiar objects/actions where a truthful drawing exists; unsupported IDs return an empty string so callers retain a readable semantic fallback. Artwork is decorative inside an accurately named button; informative standalone images need a nearby caption or accessible name. Use explicit paths/shapes, predictable viewBoxes and no remote fonts, scripts, images or network dependency. Avoid gradients/masks with colliding IDs when the same object appears repeatedly. Older objects lose faces/ornament, not recognizability.

Shared `data-appearance-age` and `data-appearance-band` hooks drive spacing, typography and visual maturity. Existing routes, engine controllers, game selectors, progress keys, answer evaluation, interruption handling and drawing storage remain intact. Engine owners insert helper output where object IDs already exist. CSS owns responsive surfaces, not correctness. Never infer the answer from a CSS class or decorative scene. A family header uses generic artwork rather than the current round's solution.

## Review and acceptance

1. Account for all 34 mode IDs in catalog, routing and a completed gameplay matrix. Check exact ages 2–10 for difficulty data; inspect representative ages 2, 5, 7 and 10 visually and the remaining ages where layout changes.
2. Capture phone 375 × 812 and 812 × 375, compact 320 × 568, tablet 820 × 1180 and 1180 × 820. Check no horizontal viewport overflow against the configured width and `documentElement.clientWidth`, since mobile `innerWidth` may expand to mask overflow. Check no clipped modal actions, ≥48px interactive bounds, legible math and coherent focus order. An internal scroll area must be intentional and keyboard accessible.
3. For every question engine: wrong attempt, explicit Hint, correct completion, replay/new round, navigation away/back and support change. No stale awards, no revealed solution by default, no auto-advancing inaccessible controls.
4. Preserve drawing pixels, Undo/Redo, templates, draft restore and export through rotation, mode change and age change. Preserve audio successful-playback gating, physical-device volume behavior and interruption recovery.
5. Review actual rendered images; automated target sizes do not verify illustration quality or enjoyment. Child/family playtesting remains separate: observe whether the child understands the first action, can recover, explains a strategy and wants another round. Do not report that evidence until observed.
